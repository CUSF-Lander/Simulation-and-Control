### Code Outline



**startup.m** Run this to generate the necessary matrices. The A, B and H_imu matrices will be stored in get_Jacobians.m, while the kalman gains will be stored in kf_20.csv and kf_100.csv



**simulink\_vars.m** Set the parameters of the drone and the Kalman filter (e.g. sensor noise), equilibrium point etc.



**kalman\_filter.m** The code of the filter itself.



**generate\_jacobians.m** Generates the state transition, control, and IMU measurement matrix, using the relevant functions. These matrices are stored in symbolic form in **get\_Jacobians.m**.



**get\_Jacobian.m** Stores the jacobians, in function form, automatically generated by **generate\_jacobians.m.**



**calculate\_kalman\_gain.m** Defines the measurement matrices for the barometer and GPS and calculates the Kalman gain matrices.



**new\_strategy\_integrated.m** Generates the control gain matrices.



**expanded\_drone\_dynamics.m** State transition function used by the Kalman Filter. Uses the 18 × 1 state vector. 



**drone\_dynamics.m** State transition function used in the simulation of the actual drone. Uses just the 12 × 1 state vector. 



**simulink\_drone\_offline\_kalman.slx** Simulink simulation of the drone control system with the integrated Kalman filter.



**sensors/** Contains the measurement functions.
