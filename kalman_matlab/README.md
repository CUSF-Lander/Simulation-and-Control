### Code Outline



**startup.m** Run this to automatically run all the relevant programs and generate the necessary matrices



**simulink\_vars.m** Contains the parameters of the drone and the Kalman filter (e.g. sensor noise), equilibrium point etc.



**kalman\_filter.m** This file contains the code of the filter itself.



**expanded\_jacobian.m** Generates the state transition, control, and IMU measurement matrix, using the relevant functions. These matrices are stored in symbolic form in get Jacobians.m.



**get\_Jacobian.m** Stores the jacobians, in function form, automatically generated by **expanded\_jacobian.m.**



**offline\_kalman\_expanded.m** Takes the numeric form of the matrices, defines more like the measurement matrices for barometer, GPS, process noise covariance, and calculates the Kalman gain matrices.



**new\_strategy\_integrated.m** Generates the control gain matrices.



**expanded\_drone\_dynamics.m** This is the state transition function used by the Kalman Filter. Uses the 18 × 1 state vector. 



**drone\_dynamics.m** This is the state transition function used in the simulation of the actual drone. Uses just the 12 × 1 state vector. 



**simulink\_drone\_offline\_kalman.slx** Simulink simulation of the drone control system with the integrated Kalman filter.



**sensors/** This folder contains the measurement functions.
